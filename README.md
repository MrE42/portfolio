# Elijah Schoneweis Portfolio

Personal software engineering portfolio built with Astro. The site presents gameplay engineering, computer vision, empirical software engineering research, professional experience, and travel photography.

## Pages

- `/` - Selected engineering projects and experience
- `/beyond-code/` - Travel, diving, and interests outside software

## Development

Requires Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

The local site is available at `http://localhost:4321`.

## Production Build

```sh
npm run build
npm run preview
```

Astro writes the static production site to `dist/`.
